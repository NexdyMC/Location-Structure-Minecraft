# Locate Structure Minecraft

Aplikasi desktop pencari structure minecraft menggunakan bahasa pemogaraman python dengna library customtkinter. cocok untuk player pemula yang ingin belajar speedrun yang mendukung versi 1.16 dan 1.16


## Fitur
- menggunakan versi 1.16 - 1.16.1
- penambahan jarak min dan max
- menggunakan shortcut <enter>
