# Locate Structure Minecraft

Aplikasi desktop pencari structure minecraft menggunakan bahasa pemogaraman python dengna library customtkinter. cocok untuk player pemula yang ingin belajar speedrun yang mendukung versi 1.16 dan 1.16


## Fitur
- menggunakan versi 1.16 - 1.16.1
- penambahan jarak min dan max
- menggunakan shortcut enter yang langsung dicari

## Panduan Penggunaan
1. Unduh: Unduh file arsip yang telah disediakan di bawah.
2. Ekstrak: Pastikan file tersebut telah diekstrak (dikeluarkan) dari folder kompresinya.
3. Jalankan: Buka folder hasil ekstrak, lalu jalankan file LocationSMC.exe.
4. Konfigurasi: Masukkan seed dan pilih versi yang sesuai. Jangan lupa untuk menentukan structure (struktur) dan dimension (dimensi) yang ingin dicari.
5. Eksekusi: Klik tombol Search untuk mulai mencari lokasi struktur tersebut.
